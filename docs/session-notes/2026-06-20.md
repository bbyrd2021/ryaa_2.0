### Bugs caught in review (all fixed)
- `from colllections.abc` (3 L's) → `collections` — instant `ImportError`.
- `Field(defualt_factory=...)` on the User PK → `default_factory` — without it `id` had no default,
  every insert would fail.
- `postgresql+asyncpg://` → `postgresql+psycopg://` — asyncpg is async-only; the engine is sync.
- Dropped `from __future__ import annotations` in `db_models.py` — breaks SQLModel `table=True`
  (annotations must be evaluable at class creation).
- **`import ryaa.db_models  # noqa: F401` inside `init_db()`** — required, or `create_all` registers
  ZERO tables (it only sees imported models). The editor's "remove unused imports on save" kept
  stripping it; the `# noqa: F401` stops that.
