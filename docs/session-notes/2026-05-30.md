## Bugs hit & lessons learned (Brandon)
- `reasons` used before defined → must `reasons: list[str] = []` first.
- `calendar_result.reasons` AttributeError — **caught by mypy, would've been MASKED at runtime by the broad `except`.** Lesson: catch-all excepts hide bugs; static types catch what hope doesn't.
- **`finally` vs `except`**: `finally` = always-runs cleanup; `except` = handle/deny. Fail-closed needs `except`.
- **pytest fixtures are matched by NAME, not type** — annotating a fixture param with an unimported type (`fake_provider: FakeProvider`) → NameError at collection. Drop the annotation.
- **`conftest.py` auto-shares fixtures, not plain classes.** Bridge a helper class via a fixture.
- **`pytest` (console script) doesn't add CWD to sys.path; `python -m pytest` does.** Fix = `pythonpath = ["."]`.
- **`type[X]` vs `X`**: fixture returning `FakeProvider` (class) vs `FakeProvider()` (instance). Test needed the class to construct custom instances.
