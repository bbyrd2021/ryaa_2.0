  - `npm install --prefix` quirk = didn't save to package.json → got pruned → Vite "failed to resolve import."
  - Built for React 18; tried pinning React 18 — still broke. Restored React 19.

  - **Glass edge-lighting**: bright border top+left, faint shadow bottom+right.
